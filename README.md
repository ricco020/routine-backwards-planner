# Routine builder (backwards planner)

Free, single-file browser tool: list the steps of a routine with how long you think each takes, set the time you must be done, and get the clock time to start every step, working backwards, with a buffer you choose. Log how long steps really took and it suggests the buffer your own timings call for. Print and CSV export.

Live: https://ricco020.github.io/routine-backwards-planner/

Printable daily page with a routine checklist: [ADHD-friendly daily planner](https://tidysheets.shop/p/adhd-daily-planner-printable).

MIT licence. No network calls, the routine stays in localStorage. A planning tool, not a medical tool.
